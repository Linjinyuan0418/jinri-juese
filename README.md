# 今日角色 - 微信小游戏

基于之前的设计文档实现的轻量微信小游戏原型。

## 功能

- 每日随机角色 + 场景
- 1～2 个短任务 + 选择
- 根据选择生成态度标签与总结
- 本地图鉴记录（体验天数、角色、场景）
- 简洁卡片式 UI（低饱和暖色）

## 运行方式

1. 用微信开发者工具打开本目录
2. 选择「小游戏」项目
3. AppID 可用测试号
4. 编译预览

## 文件说明

- `game.js`：入口 + 状态机 + Canvas UI + 逻辑
- `config/`：角色、场景、任务配置（JSON）
- `game.json` / `project.config.json`：微信配置
